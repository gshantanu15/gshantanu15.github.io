Satellites - Parallel Programming Simulation

Tampere University coursework / Parallel computing

A satellite simulation that distributes computation-heavy orbital physics and pixel rendering across parallel CPU and OpenCL workloads.

Read project record

Context

The supplied simulation models 64 satellites moving around a mouse-controlled black hole and calculates the colour of every pixel in a 1920-by-1024 display. Repeated physics updates and per-pixel colour calculations make both stages computationally demanding.

My role

I completed the exercise individually during a Parallel Computing course at Tampere University, working from university-provided starter code and implementing the parallelization and optimization work within that foundation.

What I did

  • Parallelized the satellite physics loop with OpenMP.
  • Implemented per-pixel rendering as a two-dimensional OpenCL kernel with a CPU-device fallback.
  • Reduced repeated physics calculations and configured release compiler optimizations.
  • Used the supplied sequential reference and early-frame comparisons to check satellite state and rendered-pixel correctness.
  • Retained physics, rendering, and total frame-latency reporting.

Validation and result

The completed implementation combines OpenMP for CPU-side physics, OpenCL for per-pixel rendering, and SDL2 for display. The original parallel build passed its early-frame pixel comparisons with zero reported errors during the local capture run.

  • OpenMP
